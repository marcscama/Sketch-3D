# Sketch-3D
Very experimental plugin for Qgis - 3D viewer and freehand drawing DEM/terrain with geological section cut tool and eraser. The plugin can be used also for sphere seismic viewer in 3D from CSV .
For the moment the plugin is only for my personal use. I will not upload the source code! The plugin need a very high work so I'm looking for a real university/researcher and programmer to continue the development.
